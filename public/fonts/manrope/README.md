# Manrope Web Font Assets

These files self-host the Manrope web font used by the GCSE Russian platform.

- Font: Manrope
- Copyright: The Manrope Project Authors
- License: SIL Open Font License, Version 1.1
- Source: https://github.com/sharanda/manrope
- License text: https://openfontlicense.org/open-font-license-official-text/

The files are split into browser-friendly unicode subsets matching the previous
`next/font/google` output, so production builds do not need to fetch Google Fonts.
